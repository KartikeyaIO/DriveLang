Language Features

Program Structure & Types

A Drive script is a flat sequence of top-level statements executed from top to bottom[cite: 1]. There are no classes and no entry point boilerplate—the file itself is the program[cite: 1].

Variables & Types

Variables are assigned with = and live in the global script scope[cite: 1]. Types are inferred at runtime[cite: 1]. The four primitive types are Number, String, Frame (images), and Track (audio)[cite: 1].

// 1. Imports execute the file in the current scope[cite: 1] import "my_filters.drive"; // 2. Variable Assignment[cite: 1] x = 100; name = "Drive"; // 3. Loading Media (Returns Frame and Track types)[cite: 1] img = frame("photo.png"); music = track("audio.wav"); // 4. Exporting & Printing[cite: 1] print("Processing file {} at scale {}", name, x); export(img, "output.png");

Filter Creation & The `let` Keyword

A filter defines a per-pixel operation[cite: 1]. The body assigns new values to the output channels r, g, b, a[cite: 1]. Any channel not assigned passes through unchanged[cite: 1].

Parameters and Identifiers

Inside a filter, you automatically have access to r, g, b, a (current pixel values 0-255), x, y (coordinates), and width, height (frame dimensions)[cite: 1].

filter tint_and_brightness(factor, tint_r) { // 'let' declares an intermediate local value scoped to the enclosing block[cite: 1]. let luma = 0.299 * r + 0.587 * g + 0.114 * b; // Mutate the outgoing pixel channels[cite: 1]. r = clamp((luma * factor) + tint_r, 0, 255); g = clamp(luma * factor, 0, 255); b = clamp(luma * factor, 0, 255); }

Filter Application (The Pipeline)

The pipeline operator -> pipes a Frame or Track through a sequence of operations left to right[cite: 1]. The base value is mutated in place through each stage[cite: 1].

filter invert() { r = 255 - r; g = 255 - g; b = 255 - b; } img = frame("photo.png"); // Apply a chain of filters[cite: 1]. // Native filters like resize() and blur() do not require a declaration[cite: 1]. result = img -> resize(800, 600) -> invert() -> blur(5);

Spatial Masks

A filter stage can be restricted to a pixel region[cite: 1]. Pixels outside the mask are left unchanged[cite: 1]. Ranges follow the start..end syntax[cite: 1].

filter red_boost() { r = clamp(r + 100, 0, 255); } img = frame("input.png"); // Only apply red_boost to a 300x250 pixel region starting at (100, 50)[cite: 1]. result = img -> red_boost() [100..400, 50..300];

Audio Filters (af)

An af is a per-sample operation on a Track[cite: 1]. The body assigns new values to l (left channel) and r (right channel)[cite: 1].

Audio Identifiers

Inside an audio filter, you have access to l, r, time (Time of this sample in seconds), and sr (Sample rate)[cite: 1].

af auto_pan(speed, master_gain) { // Calculate an oscillating pan value using 'time'[cite: 1] let pan = sin(time * speed); // Apply pan and gain to the left and right channels[cite: 1] l = clamp(l * (1.0 - pan) * master_gain, -1.0, 1.0); r = clamp(r * (1.0 + pan) * master_gain, -1.0, 1.0); } sound = track("music.mp3"); processed = sound -> auto_pan(2.5, 1.2); export(processed, "output.wav");

Kernels (Convolution)

A kernel defines a convolution matrix[cite: 1]. The matrix must be square, and all entries must be numeric literals[cite: 1]. The kernel is automatically normalised by dividing by the sum of its weights[cite: 1].

// Declare a 3x3 sharpen kernel[cite: 1] kernel edge_detect = [ [-1, -1, -1], [-1, 8, -1], [-1, -1, -1] ]; img = frame("photo.png"); // Kernels are applied as a filter stage in a pipeline[cite: 1] result = img -> edge_detect();

Prelude Functions

DriveLang ships with several built-in native operations and functions that do not require explicit declarations[cite: 1].

I/O & Utilities

  • print("value is {}", x): Writes to stdout. Numbers print as integers if they have no fractional part[cite: 1].
  • export(media, "output_path"): Exports a Frame as PNG or a Track as WAV (32-bit float). The path must be a string literal[cite: 1].

Media Loading (Constructors)

  • frame("path"): Loads an image file (PNG, JPG, etc.) as RGBA[cite: 1].
  • blank(width, height): Creates a transparent black RGBA frame[cite: 1].
  • text(str, font_path, size, r, g, b): Rasterizes a string into a frame using the given TTF font and RGB colour[cite: 1].
  • track("path"): Decodes an audio file (MP3, FLAC, OGG, WAV, etc.)[cite: 1].
  • silence(duration, sample_rate, channels): Creates a silent track of the given duration[cite: 1].

Native Frame Pipeline Operations

These are applied via the pipeline operator (->) without needing a filter declaration[cite: 1].

  • resize(w, h): Performs nearest-neighbour resize[cite: 1].
  • crop(x, y, w, h): Extracts a rectangular region[cite: 1].
  • blend(x, y, frame2, alpha): Alpha-composites frame2 onto the base at (x, y)[cite: 1].
  • blur(size): Generates a box-blur kernel dynamically based on radius[cite: 1].

Control Flow

Drive supports for loops iterating over a range, and if / else / elif inside filters and at script level[cite: 1]. Conditionals evaluate any non-zero number as truthy[cite: 1].

filter threshold(level) { let luma = 0.299 * r + 0.587 * g + 0.114 * b; // Conditional inside a filter runs per-pixel[cite: 1] if luma > level { r = 255; g = 255; b = 255; } else { r = 0; g = 0; b = 0; } } // Iterates i over a range[cite: 1] for i in 0..10 { print("Processing frame iteration {}", i); } // Conditional at the script level[cite: 1] quality = 1; if quality == 1 { img -> blur(3); }

Built-in Math Functions

DriveLang ships with standard mathematical functions[cite: 1].

  • abs(x)
  • min(a, b) / max(a, b)
  • clamp(x, min, max)
  • lerp(a, b, t)
  • smooth_lerp(a, b, t)
  • sin(x) / cos(x) / tan(x)
  • sqrt(x)
  • pow(a, b)
  • floor(x) / ceil(x) / round(x)
  • log(x) / exp(x)
