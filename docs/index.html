A practical handbook for the current language

Make media move.
Write it in DriveLang.

DriveLang is a small scripting language for image editing, audio processing, and repeatable media workflows. Start with one runnable file, then build toward reusable filters, card generators, batch exports, and sound design.

01

Run a script

A DriveLang program is a .drive file. Run from a directory where its relative media paths and output folders exist.

Execute

Use the run command

Drive reads and evaluates statements from top to bottom.

Scaffold

Start a project

drive new poster creates main.drive, filters.drive, assets/, and output/.

Terminal · from the repository root
drive run examples/hello.drive
drive run examples/intro.drive

# Create a starter project; without a file, run uses main.drive
drive new poster
cd poster
drive run

# Include elapsed time in the CLI output
drive --time run main.drive
Paths resolve from your working directory. The examples load the bundled image and export to Outputs/. Make the output folder before export; DriveLang does not create missing parent directories.
02

Syntax & values

The source file is the program. There is no required main function or class declaration.

A small script
// Comments start with two slashes.
import "filters.drive";

scale = 1.25;
name = "DriveLang";
img = frame("assets/photo.png");
result = img -> resize(640, 480) -> brighten(24 * scale);
print("Rendered {} at scale {}", name, scale);
export(result, "output/result.png");
TypeMeaningCreate it with
Number64-bit floating point value.12, 0.25, sin(angle)
StringText, filenames, and f-strings."hello", f"card_{i:02}.png"
FrameRGBA image bitmap.frame(), blank(), text(), folder[index]
TrackMultichannel audio samples.track(), silence(), merge(), concat()
FolderSorted image file collection.folder(path)

Use = to assign variables. Use let name = value; for a local binding in functions, filters, and audio filters. Strings support escapes \n, \t, \r, \\, \", and \0. Import a file with import \"filters.drive\"; or a standard module with import std::color;. Imports share the current scope and each file executes once. Import aliases are not supported.

03

Expressions & math

Comparisons and logical operations produce numbers: 1 is true, 0 is false. Conditions treat any nonzero number as true.

Operators

Arithmetic: + - * /. Comparisons: == != > >= < <=. Logic: and or not. Use mod(a,b) instead of a percent operator.

Ranges

start..end includes start, excludes end. 0..10..2 steps by two. Ranges power loops and masks.

Built-in math

abs, sin, cos, tan, asin, acos, atan, atan2, sqrt, exp, log, log10, floor, ceil, round, min, max, pow, mod, clamp, lerp, and smooth_lerp. Trigonometric functions use radians. Division by zero and mod by zero return zero.

F-strings, padding, precision, and literal braces
for i in 0..3 {
    path = f"output/card_{i:04}.png";
    print(f"path={path}; ratio={(i + 1) / 3.0:.2f}; braces={{ok}}\n");
}
distance = sqrt(pow(3, 2) + pow(4, 2));

Use :04 for zero-padded whole-number formatting and :.2f for two decimal places. F-strings also accept expressions between braces.

04

Media I/O

Create Frames and Tracks from files or constructors, transform them, then export to a path.

CallResult
frame(path)Loads an image as RGBA. Common formats include PNG, JPEG, BMP, WebP and TIFF.
blank(w,h)Creates a black RGBA frame.
text(s,font,size,r,g,b)Rasterizes text using the specified TTF font and RGB color values.
track(path)Decodes audio into a Track. Current decoder supports formats including WAV, MP3, FLAC, and OGG.
silence(seconds,rate,channels)Creates silence in blocks of 1024 samples.
print(...)Writes text to stdout. Braces in format strings consume values.
export(frame,path)Writes image data as PNG, regardless of path suffix.
export(track,path)Lowercase .mp3 suffix writes MP3; other suffixes write 32-bit float WAV.
export_mp3(track,path,kbps)MP3 bitrate: 128, 160, 192, 256, 320; unsupported values use 192.
Make destination folders first. Export does not create parent directories. Audio slicing and generated silence align to blocks, not necessarily exact requested sample boundaries.

Frame metadata

Read image.width, image.height, image.name, or use the matching methods width(), height(), name(). A generated frame may have an empty name.

Text on a simple canvas
canvas = blank(960, 540);
title = text("A small story", "assets/Georgia.ttf", 48, 235, 242, 255);
card = canvas -> blend(48, 70, title, 1.0);
export(card, "output/title.png");
05

Image filters

A filter is a reusable per-pixel transformation. Change the channels you need and let the rest pass through.

A shadow lift
filter lift_shadows(amount, cutoff) {
    let luma = 0.299 * r + 0.587 * g + 0.114 * b;
    if luma < cutoff {
        let lift = amount * (1 - luma / cutoff);
        r = clamp(r + lift, 0, 255);
        g = clamp(g + lift, 0, 255);
        b = clamp(b + lift, 0, 255);
    }
}
img = frame("assets/photo.png");
finished = img -> lift_shadows(38, 150);
Channels

r, g, b, a

Current pixel channels, usually 0–255. Unassigned values pass through.

Position

x, y

Current pixel coordinates for gradients, grids, or position-dependent effects.

Dimensions

width, height

Frame dimensions for centering and scaling a per-pixel calculation.

Parameters are given at the pipeline call. Filters support local lets, math, conditionals, nested filter calls, and loops whose bounds can be evaluated when the filter compiles. Those loops are unrolled; dynamic per-pixel bounds are unsupported. Declare a filter before another filter that calls it.

06

Functions & generated cards

A user-defined fn is a recipe. Put the layout in one function, make variable pieces parameters, then call it once or in a loop.

For a graphic card, make a background, load and size artwork, rasterize heading and caption text, blend each part into position, and return the completed Frame. The caller controls the copy, accent, and output filename.

Reusable card recipe
filter backdrop() {
    r = r * 0.72; g = g * 0.76; b = b * 0.84;
}
fn make_card(title, subtitle, red, green, blue) {
    let background = blank(720, 720) -> backdrop();
    let artwork = frame("assets/cover.png") -> resize(656, 360);
    let heading = text(title, "assets/Georgia.ttf", 46, red, green, blue);
    let caption = text(subtitle, "assets/Georgia.ttf", 25, 220, 225, 235);
    return background
        -> blend(32, 42, artwork, 0.92)
        -> blend(32, 445, heading, 1.0)
        -> blend(32, 540, caption, 1.0);
}
card = make_card("NORTH STAR", "A field note from the coast", 110, 225, 210);
export(card, "output/north_star.png");
Design tip: keep canvas size, font path, margins, and typography consistent in the recipe. Parameterize only the details that change. That gives a coherent series and makes redesigns a one-function edit.

Turn the recipe into a card deck

Use conditions for small content sets
for page in 0..3 {
    if page == 0 {
        title = "FIRST LIGHT"; subtitle = "Begin with a blank page";
        red = 255; green = 190; blue = 110;
    } elif page == 1 {
        title = "OPEN WATER"; subtitle = "Let the color breathe";
        red = 100; green = 220; blue = 215;
    } else {
        title = "WIDE SKY"; subtitle = "A quiet place to land";
        red = 150; green = 175; blue = 255;
    }
    page_card = make_card(title, subtitle, red, green, blue);
    export(page_card, f"output/card_{page:02}.png");
}

Functions can include locals, conditions, loops, calls to other functions, and return. Use them for layout templates, repeated calculations, and helper logic. Keep assets and output paths relative to a clearly chosen working directory.

07

Pipelines

The arrow operator runs stages left to right on Frames or Tracks. Order changes the result.

A readable image chain
poster = frame("assets/photo.png")
    -> resize(1200, 800)
    -> saturation(0.8)
    -> blur(3)
    -> crop(0, 0, 1080, 720);
Frame stageBehavior
resize(w,h)Nearest-neighbor resize.
crop(x,y,w,h)Extracts a rectangular region.
blend(x,y,frame,factor)Interpolates all RGBA channels with an overlay; this is not alpha compositing.
blur(size)Dynamic box-blur convolution; even sizes are increased to the next odd size.
declared_filter(args)Applies a custom pixel filter. Kernels are called with no parameters.
Native audio stagesgain(db), fade_in(s), fade_out(s), reverse(), speed(factor).

Resize before a spatial effect if it should use the new dimensions; crop after if you want to trim the processed image. Custom filters can call earlier declared filters to build larger looks from small parts.

08

Conditions & loops

Use conditions to choose a processing path and loops to generate a family of results.

Pick a setting, then render variants
quality = 2;
if quality == 1 { amount = 12; }
elif quality == 2 { amount = 24; }
else { amount = 36; }

img = frame("assets/photo.png");
for i in 0..4 {
    version = img -> brightness(i * amount);
    export(version, f"output/variant_{i:02}.png");
}

Range loops

Execute the body for each value in the half-open range. The loop variable can become a filter argument or filename component.

Folder loops

for image in photos { ... } visits images in sorted order.

Conditions work in scripts, functions, image filters, and audio filters. Nonzero is true. Logical and and or evaluate both sides; they do not short-circuit.

09

Spatial masks

Add x and y ranges after a filter stage to restrict it to one rectangle. Pixels outside remain unchanged for that stage.

Warm a selected window
filter warm() {
    r = clamp(r + 22, 0, 255);
    b = clamp(b - 12, 0, 255);
}
img = frame("assets/photo.png");
result = img -> warm()[120..680, 80..420];

Syntax is filter(args)[x_range, y_range]. Range starts are included and ends excluded. [0..width, 0..height] covers the whole image. Only rectangular masks are exposed by the script parser.

10

Kernels

A kernel applies a small weight matrix around each pixel for blurs, sharpening, embossing, and edge detection.

A sharpen kernel
kernel sharpen = [
    [ 0, -1,  0],
    [-1,  5, -1],
    [ 0, -1,  0]
];
image = frame("assets/photo.png") -> sharpen();

Matrices must be square and odd-sized; entries are numeric literals. Nonzero weight sums are normalized by dividing the result by the sum. Zero-sum edge kernels remain unnormalized. Border pixels sample by clamping coordinates to the image edge. See the standard-library catalog for presets.

11

Audio

An af declaration transforms samples in a Track and can use time, sample rate, conditions, and math.

Synthesize and shape a tone
af bell(freq, level) {
    let wave = sin(6.2831853 * freq * time) * level;
    l = wave;
    r = wave;
}
sound = silence(1.5, 44100, 2)
    -> bell(440, 0.3)
    -> hard_clip(0.8)
    -> fade_in(0.15)
    -> fade_out(0.25);
export(sound, "output/bell.wav");
Variables

l, r, time, sr

Left/right samples, timestamp in seconds, sample rate in hertz.

Compose tracks

Built-ins

merge, concat, slice, channel_split, reverse, speed.

Native stages

Gain & fades

gain(db), fade_in(seconds), fade_out(seconds).

merge(a,b) sums samples and pads the shorter track with silence; it does not normalize peaks. concat requires matching sample rate and channel count. slice(track,start,end) selects complete blocks by timestamp, not exact sample boundaries. channel_split(track,0) extracts left, 1 extracts right. speed(2) doubles speed, shortens duration, and changes pitch. Silence is assembled in 1024-sample blocks and can be slightly longer than requested.

Similar names, different behavior: std::audio defines linear_gain(amount) and sample_fade_in(duration). Native pipeline gain(db) uses decibels; native fade_in(duration) is its own operation.
12

Folder batches

A Folder contains supported image files in sorted order. Process each file, or address one by a name or numeric position.

Batch export
photos = folder("assets/photos");
print(f"Found {photos.len()} images in {photos.path}\n");
for photo in photos {
    done = photo -> resize(640, 640) -> vivid();
    export(done, f"output/{photo.name}.png");
}
first = photos[0];
cover = photos["cover.jpg"];

Useful operations: photos.len, photos.len(), len(photos), photos.path, photos[0], and photos["file.png"]. len(string) returns the string's byte length. Folder loops visit recognized image formats; non-images are ignored.

Standard library

These modules are source declarations you can import, inspect, reuse, or adapt.

Imports: std::core, std::color, std::advanced, std::audio, std::kernels. Declarations share one scope: later same-named filters replace earlier ones. Both core and color define fade(amount); import order decides which one is active.

Core image filters

brightness(amount), contrast(factor), gain(amount), invert(), grayscale(), red_gain(amount), green_gain(amount), blue_gain(amount), red_only(), green_only(), blue_only(), alpha(value), opacity(amount), quantize(levels), clamp_range(min,max), clamp_low(min), clamp_high(max), gamma(value), mask_white(), mask_black(), max_channel(), min_channel(), fade(amount), opaque(), transparent().

Color looks

sepia(), hdr(strength), hdr2(strength), teal_orange(amount), vintage(), warm(), cool(), vivid(), muted(), red_tint(), green_tint(), blue_tint(), cyanotype(), noir(), saturation(amount), fade(amount), purple_tint(amount), amber_tint(amount), moonlight(amount), sunset(amount), forest(amount), autumn(amount), cross_process(), bleach_bypass(amount), vibrance(amount).

How core filters behave

FilterEffect
brightness(amount)Adds amount to red, green, and blue. Negative values darken.
contrast(factor)Scales RGB distance from midpoint 128.
gain(amount)Multiplies RGB channels; this is image gain, not audio decibels.
invert(), grayscale()Invert subtracts channels from 255. Grayscale uses the simple RGB average.
red_gain, green_gain, blue_gainMultiply one selected channel. The *_only() filters keep that channel and zero the other two.
alpha(value), opacity(amount)Set alpha or multiply the current alpha.
quantize(levels)Bucket RGB values into fewer levels for a posterized look.
clamp_range(min,max), clamp_low(min), clamp_high(max)Bound RGB channels to a range, minimum, or maximum.
gamma(value)Apply a power curve to normalized RGB values.
mask_white(), mask_black()Set RGB to white or black while leaving alpha unchanged.
max_channel(), min_channel()Move channels toward the largest or smallest channel value.
fade(amount), opaque(), transparent()Core fade scales alpha; opaque sets alpha to 255; transparent sets it to 0.

bleach_bypass(amount)Mix toward gray and increase contrast.

14

Tricks & current limits

Small habits keep a script repeatable. The limits below describe the language surface exposed today.

Tip

Use padded names

f"image_{i:04}.png" sorts in numeric order.

Tip

Export checkpoints

Save intermediate images while building a pipeline, then keep only useful deliverables.

Tip

Normalize coordinates

Use x / width and y / height for scale-independent gradients.

Tip

Reuse the layout recipe

Keep font, canvas dimensions, margins, and typography in one function; parameterize the changing text and accents.

Tip

Know the channel ranges

Image channels use 0–255. Audio samples usually use −1–1. Trig uses radians.

Tip

Read a library formula

Standard-library filters are regular source; their math defines what each parameter does.

Current boundaries

  • No script-level video import, timeline, or video export workflow.
  • No classes, arrays, dictionaries, or import aliases. Kernel matrices are the supported matrix literal form.
  • Rectangular masks only; circle-mask internals are not exposed in script syntax.
  • Loops inside pixel filters require compile-time bounds and are unrolled.
  • Logical and/or do not short-circuit.
  • Resize uses nearest-neighbor. Blend interpolates RGBA channels, not alpha compositing.
